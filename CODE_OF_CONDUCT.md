# 行为准则 / Code of Conduct

## 中文

本准则适用于 Issues、Pull Requests 与代码审查。欢迎首次提供设备报告的用户，也欢迎对技术结论提出异议。请说明在哪台主控和目标上观察到了什么，针对证据讨论。

请勿骚扰、威胁、歧视或攻击参与者，勿擅自发布他人的身份、联系方式、设备地址、截图或日志。公开内容有问题时，可使用平台的举报入口或请求维护者处理。涉及私人信息时只提供原帖链接，不要复制敏感内容。没有私下联系方式时，可在 Issue 中仅请求联系渠道。

维护者可提醒当事人、移除内容、锁定讨论或限制参与。需要复核时，通过同一渠道提供原帖链接、背景和希望复核的处理决定。[安全问题报告](SECURITY.md)

## English

This code applies to issues, pull requests and reviews. First-time device reports and technical disagreements are welcome. Ground discussions in what was observed on a particular host and target.

Harassment, threats, discrimination and personal attacks are prohibited. Get permission before posting anyone else's identity, contact information, device address, screenshot or log. Use the platform's reporting tools or ask a maintainer to review a post. If personal information is involved, link to the original without repeating it. If there is no private contact channel, open an issue asking for one without posting details.

Maintainers may warn participants, remove content, lock a discussion or restrict participation. To ask for review, use the same channel and provide the original link, relevant context and the decision you would like reviewed. [Reporting security issues](SECURITY.md)

# Android 主控无线调试验收

本轮使用两个 Android 15 x86_64 模拟器，主控为 `emulator-5588`，目标为 `emulator-5586`。模拟器的系统调试连接用于操作测试界面、安装自有靶标和读取结果。本文的面板、镜像和目标 PNG 均来自签名发布包 RProbeDesk 1.1.0（版本码 3，APK 的 SHA-256 为 `8063461650ba0ae7bc9c0c1fab929d4f987e3468abc6d3fd54d27b83a0c67218`）。

## 准备真实的无线配对

1. 启动两台测试模拟器并连接 AndroidWifi。在目标的「关于模拟设备」中点按版本号七次，进入开发者选项，开启无线调试，允许当前网络。
2. 在无线调试主页记下**连接端口**，点「使用配对码配对设备」，另记该弹窗的**配对端口**。Windows 开发机分别执行下面两条命令，把占位符替换为此轮目标显示的端口。

   ```text
   adb -s emulator-5586 emu redir add tcp:48371:<配对端口>
   adb -s emulator-5586 emu redir add tcp:48372:<连接端口>
   ```

3. 在主控打开 RProbeDesk，点「配对」，使用 `10.0.2.2`、端口 `48371` 和目标显示的六位码。主控显示配对成功后，保存备注为 QA-Pixel、端口为 `48372` 的连接记录。
4. 点击连接，依提示在目标的通知栏查看八位设备确认码，在主控提交。主控进入面板后记下型号和一个读数。断开，再点同一条记录的「连接」，确认回到同一目标的面板；已确认且未变化的 TLS 公钥应直接通过。

## 复验镜像

在目标上安装同仓库的 `qa/fixture` 并打开。主控打开镜像后，在竖屏依次点击 TL、TR、BL、BR；每次核对目标中间的文字是否变成对应标签。点画面外的留黑区，记录文字应保持原值。旋转目标后，在同一镜像窗口再试四角。

在目标文本框输入 `A1` 检查键盘映射。主控「面板 → 复制设备信息」可提供含中文的测试文字。在镜像中选中目标文本框，点「输入文字」，将指定文字粘贴到主控对话框，点击「发送」，并在目标文本框核对中文。点「返回」关闭目标软键盘，再关闭及重新打开镜像。

| 镜像配色与截图 | 目标图库显示静态九色测试图。分别在主控系统深色与浅色模式下打开 1.1.0 镜像，九块中心点的解码 RGB 在两次运行中逐通道相等。H.264 镜像样点相对目标画面单通道最大差为 27/255。使用面板「截图」经系统选择器保存的 1080 × 2340 PNG，在全部九个样点与目标 RGB 完全相同。测试后已还原主控原系统浅色与 1.0 倍字体。[镜像里的九色图](mirror-colors.png) · [保存的目标截图](target-colors.png) |

可用 `bytes(range(256)) * 400 + bytes((0, 10, 13, 255))` 复建这份二进制样本。系统文件选择器在前台期间，开发者可用 `adb -s emulator-5588 shell dumpsys activity services dev.rprobedesk` 查看传输服务的 `isForeground=true`。本轮复核了选取完毕后服务停止。移除这项生命周期处理的早期构建会在主控进入缓存状态后被 Android 15 关闭现有 TCP socket，表现为选完目录返回时会话断开。

测试结束后使用 `adb -s emulator-5586 emu redir del tcp:48371` 和 `adb -s emulator-5586 emu redir del tcp:48372` 移除本轮映射。证据截图均来自测试模拟器；ARM64 真机、厂商 ROM、硬件解码延迟与受保护画面需单独复验。
